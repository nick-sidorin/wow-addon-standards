# Standards changelog

## 0.1.1 — 2026-11-12

- Make documented API and reusable native component discovery the first step for Blizzard-style UI requests.
- Prefer complete permitted components; document loading/security/data constraints and fall back to native artwork on addon-owned frames only when needed.
- Record the Forever window/progress-bar evidence and require source references plus an explicit client-verification boundary.

## 0.1.0 — 2026-11-10

- Extract portable localization, native design, saved-state, startup, restoration, taint/controller, testing, packaging, release and CurseForge copy practices.
- Separate confirmed Forever limitations from general engineering recommendations and unverified controller support.
- Add an Azeroth Fitness local profile starter, project-context/listing/release templates and reviewed pinned-copy adoption guidance.
- Exclude the source addon's product mechanics, personal project URLs and current release state from the shared agent rules.
- Add a pinned-commit sync tool and offline integrity check; no package manager or game-time dependency is required.
